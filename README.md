# 隐私隐藏项目（VMOS 伪装「系统桌面」+ 计算器暗码启动器）

把「已清除签名校验的 VMOS Pro 3.0.9」改造成两个无法被外人察觉的 APK，
全程由 **GitHub Actions 云端一键编译**，你只负责上传、点按钮、安装。

| 产物 | 伪装后效果 |
|---|---|
| `SystemDesktop.apk` | 名称显示为「系统桌面」，图标为桌面启动器样式；桌面**无图标**、任何常规方式都打不开；在最近任务 / 多任务中**完全消失** |
| `Calculator.apk` | 外观与包名与名称都是一台**正常计算器**（可正常运算），保留桌面图标；输入暗码 `1955` 再按 `=` 自动打开上面的 VMOS 主界面；自身同样从最近任务隐藏 |

> 打不开的时候怎么办？→ 打开「计算器」→ 依次按 `1 9 5 5` → 按 `=` → VMOS 前台启动。
> 想隐藏时：把 VMOS 划出/返回桌面即可，多任务里不会再出现它。

## 一、项目结构

```
vmos-hider/
├── .github/workflows/build.yml   # 一键编译工作流（修补主APK + 编译计算器 + 签名）
├── app-calculator/               # 伪装计算器完整 Android 工程源码
├── scripts/
│   ├── repack.mjs                # 核心：修补 + 重打包（主入口）
│   └── patch_manifest.mjs        # 清单手术 CLI（label/去入口/隐藏最近任务）
├── lib/                          # AXML 二进制编辑器、图标生成器、PNG 编码器
├── tools/axml_dump.mjs           # 清单查看/自检工具
├── inputs/                       # 可选的放原版 APK 的位置（推荐用 Release 附件）
└── keys/                         # 固定签名密钥（首次构建自动生成）
```

**修补原理（重要，决定成功率）：** 不反编译、不重编译 dex 与 resources.arsc——
只做“二进制手术”：① 直接改写二进制 `AndroidManifest.xml`（改显示名 / 摘除
桌面启动入口 / 给全部 193 个 Activity 加 `excludeFromRecents`）；② 直接替换
图标 PNG 文件后重新打包成 APK。其余文件逐字节保留，因此**不会引入重编译导致的
崩溃或依赖寻址失败**。最后在云端用固定密钥签名，即可安装。

## 二、从零上手（GitHub 网页版即可，约 15 分钟）

### 第 1 步：建仓库并上传源码
1. 打开 https://github.com/new ，仓库名随便填（如 `vmos-hider`），
   **勾选 Public/Private 均可**，不要勾选任何初始化选项，点 Create。
2. 进入仓库页 → `Add file` → `Upload files`。
3. 把本文件夹里的这些内容**全部拖进去**（支持整文件夹拖拽）：
   `.github/`、`app-calculator/`、`scripts/`、`lib/`、`tools/`、
   `inputs/`、`keys/`、`.gitignore`、`README.md`
   （不含 `analysis/` 等本地分析产物——仓库里没有它们）。
4. 页面底部填提交说明，点 `Commit changes`。

### 第 2 步：上传原版 VMOS APK（网页传大文件要用 Release）
1. 仓库页右侧点 `Releases` → `Create a new release`。
2. Tag 填：`original`（重要，工作流靠它找）
3. 标题随便填，把 `VMOS Pro_3.0.9.apk`（你那份已清除签名校验的）拖进附件框。
4. 点 `Publish release`。

### 第 3 步：运行编译
1. 仓库页顶部点 `Actions` → 左侧 `Build` → 右侧 `Run workflow`。
2. 参数可改（默认即可）：伪装名「系统桌面」、计算器包名、计算器名。
3. 点绿色 `Run workflow`，等 5–8 分钟。
4. 跑完后点这次运行，底部 `Artifacts` 里有：
   - `hidden-apks`（两个 APK：`SystemDesktop.apk`、`Calculator.apk`）
   - 首次运行还会有 `release-keystore`（密钥；如果自动提交失败，请下载并
     把 `keys/release.jks` 传回仓库根目录，之后才能覆盖升级）
5. 下载 `hidden-apks` 到平板。

### 第 4 步：安装与使用
1. 先装 `SystemDesktop.apk` → 再装 `Calculator.apk`
   （安装时若提示“未知来源”，允许即可；Play 保护弹窗选“仍要安装”）。
2. 桌面上只会看到**一个“计算器”图标**，没有任何 VMOS 痕迹。
3. 日常就用它当计算器。
4. 秘密入口：计算器里依次按 `1 9 5 5`，再按 `=` → VMOS（系统桌面）自动打开。

## 三、各伪装点的实现说明与限制（务必读）

| 你的要求 | 实现方式 | 备注/边界 |
|---|---|---|
| 名称伪装 | 把 `<application android:label>` 覆盖成「系统桌面」，设置/应用列表/屏幕使用时间里都显示这个名字 | 内部包名仍是 `com.vmos.pro`（按你的要求不改，避免依赖寻址失败） |
| 图标伪装 | 全部图标位图替换为“桌面启动器”风格图标（渐变底 + 白色应用宫格） | 图标资源引用不变，只换图片文件 |
| 入口伪装 | 删除 VMOS 的 LAUNCHER 入口（桌面无图标；设置里“打开”按钮也不可用） | 计算器用“显式组件”方式仍可拉起，无需桌面图标 |
| 最近任务/多任务无痕 | 给全部 Activity 写 `android:excludeFromRecents="true"`，进程在后台时多任务列表永远不会出现它；划出/返回桌面后同样无痕 | —— |
| 进程“隐藏” | **无法真正隐藏进程**（非 root 做不到）。系统“开发者选项→正在运行的服务”仍可见 | 对普通查看着眼点（桌面/多任务/使用统计/设置列表）均不可见 |
| 计算器伪装 | 全新源码工程：正常运算的普通计算器界面；`1955` + `=` 暗码启动 VMOS；自身也隐藏于最近任务 | VMOS 未安装时暗码静默失效（不报错不闪退），外人完全看不出 |

**已知边界（客观限制，提前说明）**
1. **使用时长统计**：会看到「系统桌面」用了多久（Android 隐私面板按应用统计无法消除，但名字不可疑）。
2. **通知**：VMOS 运行期间若系统有通知/悬浮窗提示，属于系统行为，无法隐藏。
3. **安装更新**：APK 签名必须一致才能覆盖升级。用本项目的固定密钥即可无缝升级；
   若你中途换了密钥，需先卸载旧版（VMOS 里的数据会清空）。
4. **杀后台**：如果你在设置里手动“强行停止”了「系统桌面」，计算器暗码会暂时打不开，
   需去 设置→应用→系统桌面→“打开/启动”一次恢复（不要强行停止即可）。
5. 若 ROM 的桌面/权限管理把**不显示桌面的应用**列为“可疑”，与本项目无关，属厂商策略。

## 四、日常怎么用（最省心姿势）

- **打开 VMOS**：计算器 → `1955` → `=`
- **隐藏 VMOS**：直接按 Home / 上滑返回桌面。它留在后台继续跑，但多任务看不到它；
  再想回来仍用暗码。
- **彻底不跑**：在 VMOS 里正常“退出虚拟机”后返回（同原生操作习惯）。

## 五、换名字 / 换包名 / 换图标（可选）

- 全部在 `Actions → Build → Run workflow` 的参数里改：
  - **主 APK 伪装名**：`label`（默认 系统桌面）
  - **计算器包名**：`calc_pkg`（默认 `com.lenovo.calculator2`；若安装时报
    “应用未安装/签名冲突”，说明和本机已有应用撞包名，换一个即可）
  - **计算器显示名**：`calc_name`（默认 计算器）
- **冒烟测试开关**：`main_smoke` 勾选上 = 本次保留桌面图标、能直接点开
  主 APK（适合第一次先验证“修补后的 VMOS 能正常开机运行”，不依赖计算器）；
  确认能跑后再**关掉**它重编一次，得到最终“无图标”无痕版。
- 想换伪装图标：修改 `lib/art.mjs` 顶部的颜色与 `lib/art.mjs` 里的图形代码后重新构建。

## 六、以后每次“更新重编”只需两步
1. `Actions → Build → Run workflow`（源码没动就无需再次上传 APK，Release 里的原版会被自动复用）。
2. 下载新 `hidden-apks`，直接安装覆盖（密钥固定，数据不丢）。

## 七、常见问题（FAQ）

**Q1 装 SystemDesktop.apk 报“与已安装应用签名不一致”？**
说明设备上装过别的签名的同包名应用（比如你之前自己签的版本）。先卸载旧版再装新的。

**Q2 桌面为什么没有图标？**
这就是“入口伪装”——`SystemDesktop.apk` 本来就不该有桌面图标。
打开它只用计算器暗码。设置→应用里能看到它，名字是「系统桌面」。

**Q3 装了计算器，暗码按了没反应？**
① 先确认 `SystemDesktop.apk` 已安装；② 确认没在设置里强行停止过它；
③ 输入 `1955` 后按的必须是 `=`。

**Q4 计算器会和系统自带的计算器搞混吗？**
包名我们特意选了 `com.lenovo.calculator2`（不冲突、看着像原生），
图标是标准计算器样式。若桌面上出现两个“计算器”图标，说明设备本身带计算器，属正常。

**Q5 构建失败怎么办？**
点开失败的步骤看红色日志。常见原因：① 忘了上传原版 APK 到 Release（标签 `original`）；
② Release 里 APK 文件名不是 `.apk` 结尾；③ 网络/超时——直接重跑一次即可。

**Q6 我想在自己电脑上本地构建？**
需要 JDK17 + Android SDK + Node，然后依次运行：
`node scripts/repack.mjs 原版.apk out.apk`（主APK），
计算器用 Android Studio 打开 `app-calculator` 直接构建，最后用 apksigner 签名。
手机上临时验证可用 MT 管理器等工具给 `SystemDesktop-unsigned.apk` 重签后安装。

**Q7 这样改违反软件协议吗？**
VMOS 是商业软件，自行修改/分发可能有许可风险，请仅用于个人设备自用研究，勿传播成品 APK。
